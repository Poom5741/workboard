Lesson 4 — Dashboard + Deploy

เป้าหมาย: URL ของคุณเอง เปิดได้จากมือถือ

Dashboard

การ์ดที่ดีต้องกัน 2 กับดัก: agent สร้าง "ตัวเลขสวย" แทนที่จะอ่านจาก database — และตัวเลขไม่ refresh หลังแก้ข้อมูล ใส่ทั้งสองไว้ใน criteria

Deploy

$ npx wrangler login
$ cd api && npm run deploy

เปิด URL จาก มือถือ เพิ่ม lead ชื่อตัวเอง 1 รายการ = ผ่าน แล้วโพสต์ URL ในคอลัมน์ Deployed ของ board

กติกาห้อง

  • หมดเวลา 20 นาที → ใช้ URL สาธิตของผู้สอนก่อน กลับมาแก้ตอนพัก — ห้องไม่รอคนเดียว
  • ข้อมูลบน demo ต้องเป็นข้อมูลปลอมเท่านั้น — เหตุผลอยู่ใน Lesson 5

Check

หลักฐานว่า deploy สำเร็จ คืออะไร
