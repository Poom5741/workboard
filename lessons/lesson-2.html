Lesson 2 — Execute การ์ดด้วย Spec Kit

Real teams run spec-driven development. วันนี้คุณคือ dev.

คำสั่งที่ใช้ (ZCode — ขึ้นต้นด้วย $ ไม่ใช่ /)

$ speckit-tasks  # spec → รายการงานที่เช็คได้
$ speckit-implement  # ทำทีละงาน รายงานผล

$speckit-specify / $speckit-plan ผู้สอน pre-run ให้แล้ว — ดูตัวอย่างจริงที่ app/specs/001-leaddesk/

หัวใจ: verify ก่อนเชื่อ

  1. Agent บอก "เสร็จแล้ว" — งานคุณเพิ่งเริ่ม
  2. เปิด localhost:8787 เช็คทีละ acceptance criteria
  3. ไม่ผ่านข้อไหน → สั่งกลับโดย อ้างข้อ criteria นั้น ไม่ใช่ "มันพัง"

Check

Agent บอกว่า implement เสร็จแล้ว คุณควรทำอะไรก่อน
