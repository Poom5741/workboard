Lesson 3 — Correction loop

ทักษะที่เอากลับไปใช้ทุกวัน: แก้ AI ให้ถูก โดยไม่แกะโค้ดเอง

3 ขั้นของ loop

  1. ระบุ อะไร ไม่ตรงกับ ข้อ criteria ไหน (ไม่ใช่ "มันพัง")
  2. สั่งแก้โดยอ้าง พฤติกรรมที่ควรเป็น — "ฟังก์ชันควรคืน 400 เมื่อ stage ไม่อยู่ใน 5 ค่า" ไม่ใช่ "แก้บรรทัด 52"
  3. ตรวจใหม่ + รัน test ทั้งชุด — แก้แดงแล้วพังเขียวที่อื่น = ยังไม่จบ

บทเรียนจริงจากการสร้าง LeadDesk

Agent เขียน .first(id) แบบที่ดูทำงานได้ — แต่ D1 API ต้องใช้ .bind(id).first() — test แดงจับได้ทันที 3 จุด นี่คือเหตุผลที่ test คือหลักฐาน ไม่ใช่ตัวเลือก
อีกจุด: db.exec() กับ SQL หลายบรรทัด ผ่านบนเครื่อง dev แต่พังบน D1 จริง — จับได้ตอน boot จริงเท่านั้น ทั้ง test และการรันจริง ต้องมีทั้งคู่
